# Pricing and current access

The High Signal Podcasts website and public read-only API currently have no
charge and require no account, API key, subscription, or checkout.

This page records current product behavior; it does not promise a permanent free
plan or future pricing model. Administrative ingestion and review routes are not
public product surfaces.
