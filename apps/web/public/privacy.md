# Privacy — High Signal Podcasts

The public website and read-only API currently require no reader account or
profile. The product does not ask readers to submit private podcast material.
Published records come from public podcast sources and retain attribution and
source links.

The public API has no write operations. Administrative ingestion and review
routes are protected operator surfaces. The footer loads shared SaaS Maker
navigation and Ask AI components; review their linked surfaces before submitting
information there.

Questions or corrections: https://github.com/Significant-Hobbies/on-record/issues
