# Product direction

High Signal Podcasts (on-record) indexes public statements as structured
claims. It is a High Signal sub-product with its own layout at
`podcasts.highsignal.app`, not a Daily Brief section.

A claim is a person, a stance, a date, and inspectable evidence — not a
transcript hit and not an unsourced summary.

The product should help someone decide which podcasts are worth their time,
skip episodes without losing the useful content, and follow recurring insights
across notable guests. Its first high-value indexes are evidenced books, apps,
tools, and emerging technology signals across a deliberately curated set of
podcasts. It is not a generic summarize-any-podcast service.

V1 proves the loop on four caption-rich podcasts and ten people. Later
phases add position histories, disagreement graphs, and more source types.
Whisper, user accounts, and a public write API stay out until the evidence
gate is proven on real episodes.
